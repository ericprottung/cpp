# C++ Modules (00–08)

This repository contains my solutions to the C++ Modules curriculum at 42 School. The projects progressively introduce core Object-Oriented Programming concepts and modern C++ features, including classes, inheritance, polymorphism, abstract interfaces, templates, containers, exception handling, and type conversions.

Through Modules 00–09, I explored software design principles, memory management, and the Standard Template Library (STL), building a strong foundation in C++ development while adhering to the coding standards of the 42 curriculum.
